# Contributing

Please submit additions or corrections with primary evidence. A useful paper record includes its exact title, author list, DOI or stable publication link, formal publication year or explicit preprint status, observed modalities, weather conditions, output type, and principal estimation mechanism. Record conditioning and task guidance separately.

For implementations, include the author-linked repository and identify the available model, training, inference, preprocessing, and weight resources. A README announcement is not equivalent to released implementation code. Preserve important configuration differences, including sensor subsets and externally supplied prompts or masks.

For datasets, provide the primary paper or institutional/author release, original sample-count units, splits, modalities, capture conditions, synthetic generation if applicable, alignment, reference/label types, and access/license information. Describe shared parents and derivative releases.

Keep one record per study; retain formal publication and preprint relationships. Do not attach third-party papers, images, data, or weights without permission. This repository links to the original sources.
